# MATILDA.FT


README

This is a snapshot of the code used to generate the data in the manuscript by Device, DeLongchamp, Sunday, Neuman, Riggleman, and Lee. For complete documentation and the maintained code base, please see the repo at github.com/rar-ensemble/MATILDA.FT

The source code and makefile are in the src subdirectory, and sample calculations are in the examples subdirectory.
